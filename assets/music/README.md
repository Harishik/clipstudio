# Music

Drop royalty-free or licensed tracks here (`.mp3 .m4a .wav .ogg .aac`) or set `music_dir` in the config.
`clipstudio render ... --music auto` picks one at random and ducks it under the voice.

Free sources: YouTube Audio Library (studio.youtube.com → Audio library), Pixabay Music, NoCopyrightSounds (credit
required), Free Music Archive (check each licence). Do not use commercial songs — Content ID will claim or mute the
clip. For trending TikTok/Reels sounds, add them inside the app when posting.
