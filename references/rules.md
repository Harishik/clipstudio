# Rules and reality check

## Why "basis" matters
Clipping is cutting someone else's stream and reposting it. Do it on one of these bases (saved in `PERMISSION.md`):
1. **Campaign** — a streamer/brand pays per 1,000 views (Whop, Clipster…). Follow its rules file exactly: required
   tags, mentions, length, platforms, watermark, banned content. Payouts are commonly ~$0.30–$3 per 1K views.
2. **Permission** — the streamer says clipping is fine (note where: stream title, panel, tweet, video).
3. **Own footage**.
4. **Transformative** — commentary, ranking, story, explanation added by the user.

## Platform monetisation
YouTube does not monetise "reused content": clips stitched together with little or no narrative or added value. Pure
copy-cut-repost can be posted for campaigns, but to earn from the platform itself add something: voice-over,
commentary hook, ranking, explanation. Shorts monetisation also needs 1,000 subscribers and 10M Shorts views in 90
days (or 4,000 watch hours). Be honest with the user about this.

## Hard rules (the tool's `check` blocks these)
- No leaks, "play early", "free download", cracks, or fake release info.
- No GTA Online money glitches, mod menus, AFK bots, shark-card generators, or "giveaway, DM me" posts.
- Never pretend to be Rockstar, Take-Two, or the streamer. No fake news; facts need an official source.
- Always credit the source creator unless the footage is the user's own.
- Nothing is posted without approval unless the user turned on `auto_post`.

## Being first vs being good
If everyone runs the same tool on the same streams, feeds fill with the same clip. Win by: live mode (minutes, not
hours), less-crowded languages, smaller streamers with permission, and adding something (hook, ranking, commentary).
